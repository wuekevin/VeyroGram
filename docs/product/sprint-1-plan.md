## 退出条件（Phase 2 Exit，来自 BMAD-MASTER §11）
- 登录、基础消息、基本监控贯通；每端至少有可复现的构建结果。
- WuKongIM 内部 API 暴露面负面测试通过；无默认口令/固定验证码；管理面强制 MFA。
- 备份已实现（恢复演练本身在 Phase 7，但 staging 数据须有备份）。

## 不属于本冲刺
- 任何 Phase 3+ Story（设计门禁未签字，Phase 3 批量编码不启动）。
- 小程序、客服、音视频等（Phase 4/5）。
