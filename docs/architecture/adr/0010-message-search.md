# ADR-0010 消息搜索方案（待决）
状态：Accepted（v1 范围）；服务端关键词索引为受限后续｜日期：2026-11-19
核实：WuKongIM@7b810e08 `internal/access/api` 无消息搜索接口；仅有 `/message/sync`、`/channel/messagesync*`、`/messages`。
问题：消息正文在 WuKongIM 存储，MySQL 不存正文（AD-4）；FR-33/FR-41 需要按关键词检索且遵守读取权限。
选项：A) 使用固定版本 WuKongIM 原生搜索（能力 UNVERIFIED，须源码核对）；B) 业务侧对“允许索引的字段/类型”建索引（需隐私评审、保留/删除同步）；C) 仅客户端本地搜索（跨端不一致，不满足服务端历史）。
决策：A 不可行（无原生搜索）。v1：按日期/成员/类型的历史查询走 IM 同步+MySQL 元数据可见性过滤；关键词搜索由客户端在本地已同步历史上执行（服务端不存正文）。B（业务侧索引）仅在隐私评审与 spike 通过后引入，必须同步保留/撤回/删除并遵守读取权限。
