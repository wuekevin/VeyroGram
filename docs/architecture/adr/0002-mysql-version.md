# ADR-0002 MySQL 版本：固定使用 8.0
状态：**Accepted（用户决策，2026-11-19）**
## 决策
业务主库使用 **MySQL 8.0（基线 8.0.46）**，不使用 8.4。用户明确指示。
## 已知事实与风险（已接受）
Oracle 发布说明显示 8.0 系列已于 2026-04 到达 EOL（最后版本 8.0.46），之后无官方安全补丁。该风险由用户**书面接受**，登记为 R-31。
## 缓解措施
1. 锁定到 8.0.46，部署文档写明版本与来源；不使用 8.4 才有的特性，SQL 与迁移只用 8.0 语法。
2. 数据库仅监听回环/私网、专用最小权限账号、禁止公网访问，降低未打补丁带来的暴露面（NFR-16）。
3. 订阅第三方补丁/延长支持作为运维选项（如 Percona Server for MySQL 8.0 或商业延期支持，待用户评估，不默认引入）。
4. 迁移路径预留：迁移脚本避免 8.0 专属不可移植写法；保留“升级到 8.4 LTS”的演练作为未来 Story（不在当前范围）。
5. 季度检查 8.0 相关 CVE，影响面评估写入风险登记。
## 后果
安全补丁责任上移到部署方；Release Readiness 须包含“MySQL 8.0 EOL 风险接受记录”。
