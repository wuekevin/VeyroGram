# SECURITY-THREAT-MODEL — VeyroGram（STRIDE，Phase 1 草案）

状态：Draft。基于已证实的审计事实（R-01…R-30）与架构 AD。未做渗透验证；每条缓解须在 Phase 2/3 以测试证明后才可标为已满足。

## 资产
账号/设备凭据；IM 令牌；消息与媒体内容；通讯录与社交关系；位置；管理员权限；开发者密钥与小程序包；支付与权益记录；审计日志；备份。

## 信任边界与数据流
1. 公网客户端 → Nginx(TLS) → API / Open Platform。
2. 客户端 → WuKongIM 网关(WSS/TLS-TCP)。
3. 业务服务 → WuKongIM API（内部，AD-2）；WuKongIM → 业务服务 Webhook（内部，签名）。
4. 业务服务 → MySQL/Redis/S3/第三方（SMS、推送、支付、AV 扫描）。
5. 小程序容器 ↔ 宿主 App（Bridge）。
6. 管理员浏览器 → 管理后台。

## Abuse cases（节选）
群发垃圾→限频/风控；批量加好友探测手机号→限频+哈希匹配；已被拉黑用户探测→统一失败；管理员批量导出聊天→审批+理由+审计；开发者申请过宽 scope→审核；恶意小程序收集剪贴板→显式授权+频控。
