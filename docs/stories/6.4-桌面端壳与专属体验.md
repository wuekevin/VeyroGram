# Story 6.4: 桌面端壳与专属体验

**Epic 6：统一品牌与设计系统落地（本 Story：Phase 3）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 桌面用户,
I want 三栏布局、快捷键、托盘、文件拖拽与加固的 Electron 壳,
So that 桌面不是放大的手机页，且默认安全.

## 验收标准（Acceptance Criteria）
**Given** Electron 壳
**When** 审计
**Then** 禁用 nodeIntegration、启用 contextIsolation、IPC allowlist、外部链接校验、签名更新

**Given** 桌面端
**When** 使用
**Then** 提供 Ctrl/Cmd K 搜索、文件拖拽、系统通知、托盘、离线恢复

**Given** 升级 Electron/React
**When** 构建
**Then** 使用受支持的版本并通过依赖审计

## 测试（含安全负面测试）
- 安全负面：XSS→IPC 提权、外链校验
- E2E：Playwright for Electron
- 依赖：高危漏洞清零
