# Story 19.1: 官网与下载中心

**Epic 19：官网、下载与客户端更新（本 Story：Phase 6）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 访客,
I want 官网展示价值、跨端下载、功能、隐私与公告，并可切换语言,
So that 清楚了解并获得应用.

## 验收标准（Acceptance Criteria）
**Given** 下载中心
**When** 配置
**Then** 下载链接与版本由后台控制，并展示校验信息

**Given** 官网
**When** 评估
**Then** 满足 SEO、性能预算与 WCAG 2.1 AA 验收清单

**Given** 文案
**When** 发布
**Then** 不含“绝对安全/端到端加密/无限”等未经验证的说法，隐私与条款经法务确认（OQ-4）

## 测试（含安全负面测试）
- 视觉回归与 a11y 扫描
- 性能：Lighthouse 预算
- 合规：文案审阅
