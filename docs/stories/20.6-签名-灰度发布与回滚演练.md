# Story 20.6: 签名、灰度发布与回滚演练

**Epic 20：硬化与发布就绪（本 Story：Phase 7）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 发布经理,
I want 各端签名构建、灰度发布与回滚演练，形成 Release Readiness 签字清单,
So that 可控的上线与可逆的回退.

## 验收标准（Acceptance Criteria）
**Given** 签名构建
**When** 产出
**Then** 可重复构建、带校验和与 SBOM，签名密钥受保护

**Given** 灰度
**When** 发布
**Then** 分阶段放量，指标异常自动暂停

**Given** 回滚演练
**When** 执行
**Then** 在目标时间内恢复上一版本并有记录，Release Readiness 逐项签字

## 测试（含安全负面测试）
- 演练：回滚
- 校验：构建可重复性
- 门禁：失败条件清单（高危安全、核心 E2E、不可回滚迁移、关键崩溃、许可证冲突、无恢复证明）
