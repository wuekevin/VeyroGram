# Story 5.3: 设备管理、设备锁与新设备批准流程

**Epic 5：个人资料、隐私与账号安全（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 查看登录设备并下线，开启设备锁，并通过手机号验证或已信任设备批准新设备,
So that 账号安全可见可控.

## 验收标准（Acceptance Criteria）
**Given** 设备列表
**When** 打开
**Then** 显示当前设备、其他设备、位置、最近活跃与下线按钮

**Given** 开启设备锁
**When** 新设备登录
**Then** 需验证手机号验证码（对齐官方设备锁基线），或经已信任设备批准；批准请求经 IM 系统消息送达已信任设备（推送增强见 7.4），超时 4 分钟

**Given** 异地/新设备登录
**When** 发生
**Then** 向其他设备发提醒且不含敏感消息正文

**Given** 用户拒绝新设备
**When** 选择“不是我”
**Then** 请求作废并提示修改密码，写 login_event

## 测试（含安全负面测试）
- 安全负面：设备锁绕过
- E2E：下线与批准
- 无障碍：设备页读屏
