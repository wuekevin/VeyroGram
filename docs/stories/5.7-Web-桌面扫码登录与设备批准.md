# Story 5.7: Web/桌面扫码登录与设备批准

**Epic 5：个人资料、隐私与账号安全（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 用手机扫码登录 Web/桌面，并由已信任设备批准新设备,
So that 电脑端快速且安全地登录.

## 验收标准（Acceptance Criteria）
**Given** 二维码
**When** 扫码
**Then** 一次性、带过期，手机端显示设备与位置并要求确认

**Given** 扫码登录会话
**When** 未在手机端确认
**Then** 不能读取历史消息

**Given** 请求超时
**When** 过期
**Then** 可刷新二维码

## 测试（含安全负面测试）
- 安全负面：二维码重放、钓鱼式批准
- E2E：扫码批准与拒绝
- 无障碍：批准页读屏

## 配置与回滚
- **配置/决策点：** 二维码有效期 48 秒（可配置）
- **回滚方案：** 关闭扫码登录回退到验证码
