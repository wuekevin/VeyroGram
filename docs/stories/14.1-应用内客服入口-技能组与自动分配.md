# Story 14.1: 应用内客服入口、技能组与自动分配

**Epic 14：客服系统（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 访客/用户,
I want 从通讯录进入专属客服咨询并自动匹配合适客服,
So that 快速得到帮助.

## 验收标准（Acceptance Criteria）
**Given** 通讯录内专属客服入口
**When** 登录用户咨询
**Then** 按技能组与负载自动分配，客服与用户身份有明确标记

**Given** 非工作时间
**When** 咨询
**Then** 留言转工单并在次日分派

**Given** 登录用户会话
**When** 查看
**Then** 会话与技能组隔离，仅暴露最小资料（官网匿名访客入口见 19.3）

## 测试（含安全负面测试）
- 安全负面：跨技能组/跨租户读取会话
- E2E：自动分配与留言转单
- 性能：队列与分配延迟
- 安全负面：访客消息存储型 XSS（客服后台渲染必须转义/沙箱）、匿名访客滥用限频
