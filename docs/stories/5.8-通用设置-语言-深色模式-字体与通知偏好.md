# Story 5.8: 通用设置：语言、深色模式、字体与通知偏好

**Epic 5：个人资料、隐私与账号安全（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 切换语言与深浅色主题，调整字体与通知偏好,
So that 符合个人习惯.

## 验收标准（Acceptance Criteria）
**Given** 切换语言
**When** 保存
**Then** 无需重启，至少简体中文与英文，文案走 i18n 资源

**Given** 深色模式
**When** 默认
**Then** 跟随系统，可手动选择

**Given** 字体 200%
**When** 浏览关键页
**Then** 无裁切、无重叠

**Given** 聊天背景
**When** 设置与清除
**Then** 保存并多设备同步；清空缓存清除本地媒体缓存且不影响云端数据

## 测试（含安全负面测试）
- 无障碍：200% 字号与 320px 回流
- 视觉回归：明暗与中英基线
- E2E：设置同步
