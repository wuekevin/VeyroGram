# Story 3.4: 联系人列表、个人名片与备注

**Epic 3：联系人与社交关系（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 按拼音浏览联系人，查看个人名片并设置备注,
So that 管理关系更方便.

## 验收标准（Acceptance Criteria）
**Given** 联系人
**When** 浏览
**Then** 按拼音分组排序，搜索可用

**Given** 个人名片
**When** 查看
**Then** 显示头像、昵称、备注、共同群组、来源，并受对方隐私设置约束

**Given** 修改备注
**When** 保存
**Then** 多设备同步

**Given** 联系人列表
**When** 浏览
**Then** 显示在线时长；名片显示入群方式与时间；官方与机器人账号分类展示（机器人由 16.7 提供）

## 测试（含安全负面测试）
- E2E：备注同步
- 安全负面：不可见字段不返回
- 回归：拼音排序
