# Story 9.6: 后台全新界面与状态

**Epic 9：管理后台商业运营能力（本 Story：Phase 3）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台运营,
I want 全新企业风格的后台：概览、列表、详情抽屉与完整状态,
So that 高效、一致、可访问的运营体验.

## 验收标准（Acceptance Criteria）
**Given** 每个后台页面
**When** 渲染
**Then** 具备加载、空、错误、无权限状态与真实数据动作

**Given** 键盘
**When** 操作
**Then** 全部功能可达，焦点环可见

**Given** 1024–1440 宽度
**When** 浏览
**Then** 无横向滚动与裁切

## 测试（含安全负面测试）
- 视觉回归基线
- 无障碍：a11y_scan 与人工键盘/读屏
- E2E：核心后台流程
