# Story 7.3: 会话媒体中心

**Epic 7：会话列表、搜索与通知（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 查看会话内图片、视频、文件、链接的汇总,
So that 集中找回资料.

## 验收标准（Acceptance Criteria）
**Given** 会话
**When** 打开媒体中心
**Then** 先展示图片与链接，视频与文件由 11.2 与 10.3 交付后接入；内容均受成员资格与撤回约束

**Given** 文件下载
**When** 点击
**Then** 使用短时签名 URL

**Given** 被移出群
**When** 访问
**Then** 在缓存与 URL 的 TTL 内不可见

## 测试（含安全负面测试）
- 安全负面：移出后媒体 URL 在 TTL 内失效
- E2E：分类浏览
- 性能：分页
