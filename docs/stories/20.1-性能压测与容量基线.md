# Story 20.1: 性能压测与容量基线

**Epic 20：硬化与发布就绪（本 Story：Phase 7）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台所有者,
I want 用测试环境模拟 1k→10k 连接与群发，记录硬件与流量模型,
So that 用证据而非猜测承诺规模.

## 验收标准（Acceptance Criteria）
**Given** 压测
**When** 1k→10k 逐级
**Then** 记录硬件、配置、流量模型与 SM-1/SM-8 结果

**Given** 群发与已读扇出
**When** 压测
**Then** 确定群成员与已读详情上限

**Given** before_send
**When** 压测
**Then** 记录对发送时延的影响并确定预算

## 测试（含安全负面测试）
- 压测报告存档
- 回归：基线对比
- 容量：瓶颈分析
