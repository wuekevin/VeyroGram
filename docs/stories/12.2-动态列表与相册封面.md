# Story 12.2: 动态列表与相册封面

**Epic 12：朋友圈（动态）（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 浏览好友动态，查看发布者的朋友圈，设置相册封面,
So that 关注好友近况.

## 验收标准（Acceptance Criteria）
**Given** 动态列表
**When** 浏览
**Then** 显示发布者备注名优先、头像、时间、地址与可见范围内的内容

**Given** 点击头像
**When** 查看他人朋友圈
**Then** 仅显示对自己可见的动态

**Given** 相册封面
**When** 设置
**Then** 从相册或拍摄选择并同步

**Given** 动态中的文本与图片
**When** 长按
**Then** 可复制、收藏（进入 10.1 的我的收藏）、转发或保存

## 测试（含安全负面测试）
- 安全负面：他人朋友圈越权
- E2E：列表与封面
- 视觉回归：列表状态
