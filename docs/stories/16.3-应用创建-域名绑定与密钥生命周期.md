# Story 16.3: 应用创建、域名绑定与密钥生命周期

**Epic 16：开放平台基础（本 Story：Phase 5）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 开发者,
I want 创建应用、验证域名并管理密钥,
So that 拥有可安全使用的应用身份.

## 验收标准（Acceptance Criteria）
**Given** 应用状态机
**When** 非法迁移
**Then** 被拒绝（draft→sandbox→in_review→approved→published→suspended→retired）

**Given** 域名
**When** 通过 DNS/文件校验
**Then** 才能在 manifest 声明；验证失效自动暂停相关版本

**Given** App Secret
**When** 创建或轮换
**Then** 仅展示一次，库中只存哈希，旧密钥宽限期后失效，吊销后 ≤60 秒内令牌失效

## 测试（含安全负面测试）
- 安全负面：明文密钥不入库与日志
- 集成：域名验证与失效
- E2E：创建-轮换-吊销
- 安全负面：Secret 不出现在日志、响应与错误信息中；轮换后旧密钥失效
