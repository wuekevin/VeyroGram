# Story 10.4: 文件隔离复核与存储生命周期

**Epic 10：收藏、位置与文件（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台运营,
I want 文件上传后经病毒扫描，命中的隔离，过期对象按策略清理,
So that 防止恶意文件传播并控制存储成本.

## 验收标准（Acceptance Criteria）
**Given** 命中隔离
**When** 后台复核
**Then** 仅见元数据，误隔离可申请复核并恢复

**Given** 命中隔离
**When** 通知
**Then** 发送者收到提示，后台仅见元数据

**Given** 会话被删除或文件到期
**When** 到期
**Then** 关联对象在期限内被清理且旧 URL 在 TTL 内失效

## 测试（含安全负面测试）
- 安全负面：未扫描文件不可下载
- 集成：存储生命周期 worker
- 恢复：误隔离的复核
