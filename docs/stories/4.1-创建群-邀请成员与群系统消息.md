# Story 4.1: 创建群、邀请成员与群系统消息

**Epic 4：群聊与高级群管理（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 创建群并邀请成员，群内有系统通知,
So that 多人沟通的基础.

## 验收标准（Acceptance Criteria）
**Given** 选择联系人
**When** 创建群
**Then** 创建者为群主并生成创建系统消息

**Given** 邀请成员
**When** 对方已被拉黑
**Then** 被拒；群黑名单见 4.4

**Given** 成员退出/被移除
**When** 完成
**Then** 系统消息生成且权限即时收回

**Given** 创建群
**When** 未设置群名与头像
**Then** 默认群名由成员昵称拼接，群头像由成员头像拼图

**Given** 群主退出
**When** 确认
**Then** 自动指定第二位入群成员为群主

## 测试（含安全负面测试）
- 安全负面：非成员不能读写群
- E2E：创建-邀请-退出
- 集成：群与 IM 频道订阅同步
