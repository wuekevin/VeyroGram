# Story 9.7: 通讯引擎入口（WuKongIM 后台经管理后台鉴权代理）

**Epic 9：管理后台商业运营能力（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台运维,
I want 在管理后台“运维 → 通讯引擎”进入 WuKongIM 自带后台，免二次登录且仅限有权限的管理员,
So that 统一登录、权限与审计，同时保持 WuKongIM 管理端口不对外.

## 验收标准（Acceptance Criteria）
**Given** 具备 ops.im.view 的管理员且已通过 MFA
**When** 点击“运维-通讯引擎”
**Then** 直接进入 WuKongIM 后台且不出现其登录页，并写审计（谁、何时、角色级别）

**Given** 无该权限、会话失效或未通过 MFA 的请求
**When** 访问通讯引擎路径
**Then** 一律 401/403，不向 WuKongIM 转发任何请求

**Given** 外部网络
**When** 直接访问 WuKongIM 管理端口、后台路径或带伪造 Authorization 的请求
**Then** 不可达或被剥离，暴露面闸门含此负面用例

**Given** ops.im.view 与 ops.im.admin 两个级别
**When** 分别进入
**Then** 分别映射到 WuKongIM 只读与可写管理用户，只读用户的写操作被 WuKongIM 拒绝

**Given** 管理员权限被撤销或会话结束
**When** 已打开的通讯引擎页继续请求
**Then** 在会话有效期内最迟下一次请求即被拒绝，代理签发的 WuKongIM 令牌有效期短且不落入浏览器持久存储

## 测试（含安全负面测试）
- 安全负面：未登录、无权限、无 MFA、伪造头、路径穿越、5301 直连
- E2E：授权进入-只读不可写-撤权后被拒
- 暴露面：扩展 tests/ops/test_exposure 与 nginx 白名单测试
- 兼容：WuKongIM 固定点升级后后台经代理可用的冒烟

## 配置与回滚
- **配置/决策点：** 前端免登录方式（注入令牌脚本或后台前端小补丁）、独立子域名与 CSP、WuKongIM manager 用户与密钥由部署生成（不入库）；高危操作（频道迁移、驱逐、DB 巡检）默认仅 admin
- **回滚方案：** 关闭菜单与 Nginx 代理路径即可停用；紧急情况经 SSH 隧道访问 WuKongIM 后台
