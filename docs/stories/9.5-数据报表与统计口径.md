# Story 9.5: 数据报表与统计口径

**Epic 9：管理后台商业运营能力（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台运营,
I want 查看关键运营指标，口径文档化且不含个人数据,
So that 用数据决策而不泄露隐私.

## 验收标准（Acceptance Criteria）
**Given** 报表
**When** 查看
**Then** 指标口径可查，聚合数据不含个人级信息

**Given** 导出报表
**When** 发起
**Then** 需审批并留痕

**Given** 大数据量
**When** 查询
**Then** 异步生成不拖垮在线库

## 测试（含安全负面测试）
- 安全负面：个人数据泄露检查
- 性能：报表查询对主库影响
- E2E：报表生成
