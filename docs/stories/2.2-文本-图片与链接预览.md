# Story 2.2: 文本、图片与链接预览

**Epic 2：完整的消息体验（本 Story：Phase 3）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 发送文本与最多 9 张图片，并看到链接预览,
So that 日常沟通的基本表达.

## 验收标准（Acceptance Criteria）
**Given** 发送图片
**When** 选择相册多图或拍照
**Then** 可选原图，上传有进度，失败可重试

**Given** 文本含链接
**When** 服务端取预览
**Then** 禁止内网、回环、链路本地地址，限制重定向与大小，超时 ≤5 秒

**Given** 文本含手机号
**When** 点击
**Then** 提示拨号或保存到通讯录

**Given** 文本消息含系统 emoji 或自定义表情图片
**When** 渲染
**Then** 各端一致显示（表情商店由 11.3/11.5 提供数据）

## 测试（含安全负面测试）
- 安全负面：SSRF 用例集（内网、元数据地址、重定向到内网）
- E2E：多图发送与失败重试
- 性能：大图压缩与上传耗时记录
- 安全负面：多格式混合（polyglot）图片文件被拒绝

## 配置与回滚
- **配置/决策点：** 预览抓取独立出口与超时；单图大小上限
- **回滚方案：** 关闭预览开关不影响消息发送
