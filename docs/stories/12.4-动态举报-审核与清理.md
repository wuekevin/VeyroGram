# Story 12.4: 动态举报、审核与清理

**Epic 12：朋友圈（动态）（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台运营,
I want 举报动态，后台审核下架，缓存与通知同步清理,
So that 内容安全.

## 验收标准（Acceptance Criteria）
**Given** 举报动态
**When** 提交
**Then** 进入审核队列并可追踪

**Given** 下架
**When** 完成
**Then** 对所有人在列表与接口层立即不可见并写审计，媒体 URL 在 TTL（≤5 分钟）内失效，缓存与通知被清理

**Given** 申诉
**When** 提交
**Then** 由不同审核员复核

## 测试（含安全负面测试）
- 安全负面：下架后媒体 URL 在 TTL 内失效
- E2E：举报到下架
- 审计：处置记录
