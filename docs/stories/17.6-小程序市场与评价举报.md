# Story 17.6: 小程序市场与评价举报

**Epic 17：小程序运行时与市场（本 Story：Phase 5）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 浏览、搜索、查看详情与评价，收藏与历史，举报小程序,
So that 发现好用且可信的应用.

## 验收标准（Acceptance Criteria）
**Given** 下架或被判恶意
**When** 浏览与搜索
**Then** 不出现在任何列表

**Given** 详情页
**When** 查看
**Then** 显示申请的权限与用途

**Given** 评价与举报
**When** 提交
**Then** 限频防刷，同一用户对同一应用仅保留一条有效评价，举报量达阈值触发复审

## 测试（含安全负面测试）
- 安全负面：刷评与恶意举报
- E2E：浏览-评价-举报
- 视觉回归：市场页
