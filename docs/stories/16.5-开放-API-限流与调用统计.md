# Story 16.5: 开放 API、限流与调用统计

**Epic 16：开放平台基础（本 Story：Phase 5）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 开发者,
I want 调用独立监听的开放 API，有限流、幂等与统计,
So that 稳定可预期的集成.

## 验收标准（Acceptance Criteria）
**Given** 超限
**When** 调用
**Then** 返回 429 与 Retry-After，错误含 trace_id

**Given** 个人用户 API 令牌
**When** 调用开放 API
**Then** 被拒绝

**Given** 统计
**When** 查看
**Then** 为聚合口径，不含个人数据

## 测试（含安全负面测试）
- 安全负面：令牌混用
- 合约：OpenAPI 3.1 与 SDK 样例
- 性能：限流准确性
