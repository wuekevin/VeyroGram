# Story 18.1: 套餐与权益服务

**Epic 18：订阅、权益与支付（本 Story：Phase 6）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 获得由服务端强制的套餐权益与配额,
So that 功能与配额可控可审计.

## 验收标准（Acceptance Criteria）
**Given** 套餐变化
**When** 生效
**Then** 权益实时更新并可审计

**Given** 客户端
**When** 尝试本地开启付费功能
**Then** 服务端拒绝

**Given** 配额
**When** 超限
**Then** 在 before_send 或接口层被拒并提示升级

## 测试（含安全负面测试）
- 安全负面：绕过权益检查
- E2E：套餐变更与配额
- 回归：权益默认值
