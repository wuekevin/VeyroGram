# Story 1.14: 登录与设备页客户端（四端最小实现）

**Epic 1：账号与最小聊天纵切（可信基座）（本 Story：Phase 2）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在四端用手机号登录并管理设备,
So that Phase 2 的登录纵切在四端可用.

## 验收标准（Acceptance Criteria）
**Given** 登录页
**When** 输入手机号与验证码
**Then** 登录成功并把令牌保存到系统安全存储，错误与限流有明确提示

**Given** 设备列表
**When** 打开
**Then** 显示当前设备与其他设备并可下线（界面使用设计令牌与图标库，不沿用上游样式）

**Given** 键盘与读屏
**When** 操作登录与设备页
**Then** 全部可达、焦点环可见、控件有名称

## 测试（含安全负面测试）
- E2E：四端登录与下线
- 无障碍：a11y_scan 与人工键盘检查
- 安全负面：令牌不出现在日志与备份中
