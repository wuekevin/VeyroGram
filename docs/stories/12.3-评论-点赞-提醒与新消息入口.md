# Story 12.3: 评论、点赞、提醒与新消息入口

**Epic 12：朋友圈（动态）（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 评论点赞好友动态并被提醒，从新消息入口查看,
So that 互动与触达.

## 验收标准（Acceptance Criteria）
**Given** 动态可见
**When** 评论或点赞
**Then** 只有互为好友且可见的人能看到彼此的互动

**Given** 被提醒
**When** 通知
**Then** 收到提醒并可进入动态

**Given** 删除动态
**When** 完成
**Then** 评论、点赞、缓存与通知同步清除

## 测试（含安全负面测试）
- 安全负面：互动可见性泄露
- E2E：互动与删除清理
- 性能：通知扇出
