# Story 8.4: 可信代理与真实客户端 IP

**Epic 8：举报、内容安全与风控（本 Story：Phase 3）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台运营,
I want 只信任可信代理列表中的转发头来取得真实 IP,
So that 防止伪造 IP 绕过限速.

## 验收标准（Acceptance Criteria）
**Given** 请求来自非可信代理
**When** 带 X-Forwarded-For
**Then** 忽略并使用 socket 地址

**Given** WuKongIM PROXY 协议
**When** 启用
**Then** 仅接受 Nginx 网段

**Given** CDN 变更
**When** 更新可信 CIDR
**Then** 热加载并写审计

## 测试（含安全负面测试）
- 安全负面：头注入用例
- 集成：Nginx 与 IM 联调
- 配置：CIDR 校验
