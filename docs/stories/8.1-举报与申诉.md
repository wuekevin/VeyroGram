# Story 8.1: 举报与申诉

**Epic 8：举报、内容安全与风控（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 举报用户、群、消息，并对处置申诉（动态举报见 12.4）,
So that 有渠道对抗滥用，也有救济.

## 验收标准（Acceptance Criteria）
**Given** 举报
**When** 提交
**Then** 进入后台工单并可追踪状态

**Given** 被处置用户
**When** 申诉
**Then** 由与处置人不同的审核员处理

**Given** 处置完成
**When** 通知
**Then** 双方收到结果且写审计

**Given** 群设置与用户资料页
**When** 点击投诉
**Then** 可投诉本群或该用户并进入举报队列（9.3 通用化队列）

## 测试（含安全负面测试）
- 安全负面：举报接口限频、防刷
- E2E：举报到处置
- 合规：申诉时限配置
