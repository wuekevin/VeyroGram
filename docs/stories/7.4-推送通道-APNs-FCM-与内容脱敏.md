# Story 7.4: 推送通道（APNs/FCM）与内容脱敏

**Epic 7：会话列表、搜索与通知（本 Story：Phase 3）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 通过 APNs、FCM 与厂商通道收到通知，正文可脱敏,
So that 不错过消息且不泄露隐私.

## 验收标准（Acceptance Criteria）
**Given** 推送
**When** 发送
**Then** 默认正文可配置为“你有一条新消息”，不含敏感内容

**Given** 通道
**When** 设备注册
**Then** 按设备类别选择 APNs 或 FCM，密钥不入源码；国内厂商通道见 7.6

**Given** 推送失败
**When** 重试
**Then** 退避后记录失败率并告警

## 测试（含安全负面测试）
- 安全负面：通知内容审计；密钥扫描
- 集成：沙箱推送
- 监控：推送成功率
- 安全负面：推送令牌劫持/重绑定、跨用户推送

- **回滚方案：** 通道可逐一关闭
