# Story 16.1: 开发者注册与主体认证

**Epic 16：开放平台基础（本 Story：Phase 5）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 开发者,
I want 注册个人或企业主体并完成认证,
So that 获得上架与高风险权限的资格.

## 验收标准（Acceptance Criteria）
**Given** 未认证主体
**When** 提交上架或申请需实名 scope
**Then** 被拒绝，只能创建沙箱应用

**Given** 认证材料
**When** 存储
**Then** 加密，访问需理由并留审计，可按保留策略删除

**Given** 认证审核
**When** 完成
**Then** 通知开发者并记录结论

## 测试（含安全负面测试）
- 安全负面：未认证主体越权上架
- 合规：认证材料保留与删除
- E2E：认证流程
