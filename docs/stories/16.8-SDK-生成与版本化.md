I want 使用 TS/Go/Android/iOS SDK,
So that 更快接入.

## 验收标准（Acceptance Criteria）
**Given** OpenAPI 契约
**When** 发布
**Then** 生成并版本化四种 SDK，带兼容窗口

**Given** SDK 版本
**When** 发布
**Then** 带兼容窗口与变更日志

**Given** SDK 示例
**When** CI
**Then** 在沙箱上端到端运行

- 视觉回归与 a11y 扫描
