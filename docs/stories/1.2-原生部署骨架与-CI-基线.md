# Story 1.2: 原生部署骨架与 CI 基线

**Epic 1：账号与最小聊天纵切（可信基座）（本 Story：Phase 2）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台所有者,
I want 原生 systemd 部署骨架与 CI 基线,
So that 后续每个 Story 都能被可重复地构建、部署与回滚.

## 验收标准（Acceptance Criteria）
**Given** 已按 infrastructure/systemd 部署
**When** 检查进程
**Then** 服务以非 root 专用账号运行，/healthz 与 /readyz 仅内网可达

**Given** 提交 PR
**When** CI 运行
**Then** 执行 lint、go test -race、OpenAPI diff、模块依赖方向检查，任一失败则阻断

**Given** 部署产物
**When** 构建
**Then** 二进制与 systemd unit 版本化、可回滚，Nginx 模板仅转发白名单路径

## 测试（含安全负面测试）
- 集成：systemd 单元在干净主机上安装、重启、回滚演练
- CI：lint、go test -race、OpenAPI diff、依赖方向检查全部为必过门禁

## Dev Agent Record（2026-11-20）
**实现：** `infrastructure/systemd/veyrogram-api.service`（专用非 root 账号、沙箱、EnvironmentFile、能力清空）；`infrastructure/nginx/veyrogram-api.conf.template` + `render-nginx.sh`（仅转发 `/v1/`，其余 404，覆盖而非追加 X-Forwarded-For，TLS≥1.2）；`infrastructure/scripts/{lib,deploy,rollback}.sh`（版本不可变、校验和、`-check-config` 预检、原子切换、就绪等待、失败自动回滚）；服务新增 `-check-config`/`-version`；`services/api/internal/archtest`（AD-1 依赖方向检查）；`tools/lint_infra.py`、`tools/openapi_diff.py`、`tools/ci_local.sh`、`.github/workflows/ci.yml`。
**测试（均已实际运行）：** `tools/ci_local.sh` 全部通过——go fmt/vet/`test -race`（含 AD-1 夹具：10 种违规都会被抓到）、infra 策略 lint（18 项单测）、OpenAPI diff（16 项单测）、`tests/ops/test_deploy.sh`（14 项：成功部署、校验和不符拒绝、版本串穿越拒绝、预检失败不切换、就绪失败自动回滚、手动回滚、版本不可变）、`tests/ops/test_nginx.sh`（17 项真实 nginx：`nginx -t`、仅 `/v1/` 转发、伪造 XFF 被覆盖、`/healthz /readyz /metrics` 等 404 且不到达上游、TLS1.1 拒绝）。
**变异验证：** 去掉校验和检查或自动回滚，部署演练测试失败；把 `/healthz` 加入代理，nginx 测试失败。
**验收标准状态：** AC2（CI 门禁）✔ 本地全绿，但**尚未在 GitHub Actions 上运行**，且“设为必过检查”是仓库分支保护设置，不在代码里；AC3 ✔（二进制与 unit 版本化可回滚；Nginx 仅白名单）；AC1 部分 ——unit 内容经静态策略检查与审阅满足“非 root 专用账号”，**在真实 Linux + systemd 上安装/重启/回滚的演练尚未做**（本机是 macOS，用可替换的重启命令演练了脚本逻辑）。
**未做/待办：** ① 干净 Linux 主机上的真实 systemd 演练；② GitHub 上首次运行 CI 并配置分支保护（目录当前不是 git 仓库，“OpenAPI diff vs base ref”在本地因无基线而空过）；③ systemd unit 的 `MemoryDenyWriteExecute` 等沙箱项需在目标发行版上用 `systemd-analyze security` 复核；④ 宝塔对 Nginx 配置的托管方式需现场确认；⑤ `packages/contracts/openapi` 尚无规范文件，OpenAPI diff 目前只有逻辑与测试，无真实对象。
