# Story 16.4: OAuth 授权码 + PKCE 与同意页

**Epic 16：开放平台基础（本 Story：Phase 5）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在宿主绘制的同意页里按最小 scope 授权应用，并随时撤销,
So that 授权透明可控.

## 验收标准（Acceptance Criteria）
**Given** 授权码流程
**When** 缺少 PKCE 或 state、重定向 URI 不精确匹配
**Then** 被拒绝，授权码一次性且 ≤5 分钟

**Given** 同意页
**When** 展示
**Then** 由宿主绘制，列出 scope 的用户可读说明与数据用途，可部分同意，应用无法伪造或遮挡

**Given** 撤销
**When** 完成
**Then** 访问令牌 ≤60 秒内失效，刷新令牌复用触发整链吊销并告警

## 测试（含安全负面测试）
- 安全负面：OAuth 攻击集（开放重定向、码窃取、scope 膨胀）
- E2E：授权-撤销
- 无障碍：同意页读屏与键盘
