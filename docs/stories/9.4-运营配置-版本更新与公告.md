# Story 9.4: 运营配置、版本更新与公告

**Epic 9：管理后台商业运营能力（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台运营,
I want 功能开关、下载链接、版本更新、公告可在后台配置,
So that 无需发版即可运营.

## 验收标准（Acceptance Criteria）
**Given** 配置变更
**When** 保存
**Then** 生成版本历史并可回滚

**Given** 版本配置
**When** 保存
**Then** 保存最低版本、强制更新开关与灰度比例字段（客户端行为见 19.2，发布演练见 20.6）

**Given** 页面
**When** 加载失败或无数据
**Then** 有 Loading/Empty/Error 状态

**Given** 官方/系统账号
**When** 配置
**Then** 在后台创建系统账号与官方标识，客户端据此显示

**Given** 客户端“关于/检查新版本”
**When** 点击
**Then** 读取版本配置并提示（升级行为见 19.2）

## 测试（含安全负面测试）
- 安全负面：配置越权；非法下载链接
- E2E：改配置-客户端生效
- 回归：版本历史
