# Story 17.5: 灰度、回滚与下架

**Epic 17：小程序运行时与市场（本 Story：Phase 5）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 开发者,
I want 按比例灰度，监控自动暂停，一键回滚与紧急下架,
So that 安全发布.

## 验收标准（Acceptance Criteria）
**Given** 灰度
**When** 错误率超阈值
**Then** 自动暂停并告警

**Given** 回滚
**When** 触发
**Then** 新开启的小程序使用上一版本 [目标 ≤5 分钟]，被下架应用对已授权用户发通知

**Given** 紧急下架
**When** 触发
**Then** 下次启动不可用并写审计

## 测试（含安全负面测试）
- 集成：灰度比例与回滚演练
- 安全负面：已下架包不可再加载
- E2E：灰度-暂停-回滚
