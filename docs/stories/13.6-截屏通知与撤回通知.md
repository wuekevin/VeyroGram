# Story 13.6: 截屏通知与撤回通知

**Epic 13：旗舰消息能力（本 Story：Phase 3）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在系统支持时发送截屏通知，撤回时显示撤回提示,
So that 知情与透明.

## 验收标准（Acceptance Criteria）
**Given** 平台支持截屏检测
**When** 截屏
**Then** 在会话显示系统通知（可由设置开关）

**Given** 平台不支持
**When** 设置页
**Then** 隐藏该选项并说明替代交互

**Given** 界面文案
**When** 展示
**Then** 明确“并非所有平台/场景可检测截屏”

**Given** 敏感会话
**When** 启用防截屏（拦截）
**Then** Android 使用 FLAG_SECURE、iOS 使用安全视图；平台不支持处明确声明不提供拦截

## 测试（含安全负面测试）
- E2E：支持与不支持平台
- 合规：文案不承诺全面检测
- 回归：开关
