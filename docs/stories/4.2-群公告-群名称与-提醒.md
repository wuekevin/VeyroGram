# Story 4.2: 群公告、群名称与 @ 提醒

**Epic 4：群聊与高级群管理（本 Story：Phase 3）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 设置群公告与名称，@成员或 @所有人,
So that 重要信息触达群成员.

## 验收标准（Acceptance Criteria）
**Given** 群主或管理员
**When** 修改公告
**Then** 生成系统消息与未读提醒，普通成员无权修改

**Given** @所有人
**When** 超过频率或角色不允许
**Then** 被拒绝

**Given** 被 @ 成员免打扰
**When** 收到
**Then** 会话列表仍显示醒目标记

## 测试（含安全负面测试）
- 安全负面：普通成员改公告被拒
- E2E：@ 提醒
- 回归：免打扰与 @ 的优先级
