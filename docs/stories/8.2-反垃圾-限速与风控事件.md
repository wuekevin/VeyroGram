# Story 8.2: 反垃圾、限速与风控事件

**Epic 8：举报、内容安全与风控（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台运营,
I want 策略可配置的限速与风控规则，命中写事件可复核,
So that 压制群发与异常登录.

## 验收标准（Acceptance Criteria）
**Given** 异常行为
**When** 命中规则
**Then** 限速或拦截并写 risk_event，可在后台复核与解除

**Given** 误伤
**When** 解除
**Then** 恢复并记录原因

**Given** 规则变更
**When** 保存
**Then** 版本化并可回滚

## 测试（含安全负面测试）
- 安全负面：绕过限速的尝试
- 回放：历史事件回放验证规则
- 性能：规则评估对 before_send 时延的影响
