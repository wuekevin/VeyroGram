# Story 3.2: 黑名单

**Epic 3：联系人与社交关系（本 Story：Phase 3）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 拉黑或解除拉黑用户,
So that 避免骚扰.

## 验收标准（Acceptance Criteria）
**Given** 用户 A 拉黑 B
**When** B 发消息
**Then** 经 IM 原生黑名单拒绝且 B 看到统一失败状态

**Given** 拉黑生效
**When** 涉及群邀请或动态可见性
**Then** 由 4.4 与 12.1 接入同一黑名单服务（本 Story 提供查询契约）

**Given** 解除拉黑
**When** 完成
**Then** 恢复沟通但不恢复已删除的好友关系

**Given** 被拉黑方
**When** 查看拉黑方资料
**Then** 不可查看（统一失败，不泄露拉黑）

## 测试（含安全负面测试）
- 安全负面：被拉黑方不能通过任何入口发起会话
- 集成：IM 黑名单同步
- E2E：拉黑与解除
