# Story 4.8: 群设置页与成员列表

**Epic 4：群聊与高级群管理（本 Story：Phase 3）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在群设置里查看成员、在线人数、保存的群聊与设置,
So that 一站式查看群信息.

## 验收标准（Acceptance Criteria）
**Given** 群设置
**When** 打开
**Then** 显示总成员数、在线人数、公告与自己的角色

**Given** 保存群聊
**When** 开启
**Then** 出现在通讯录“保存的群聊”

**Given** 大群
**When** 成员列表分页
**Then** 保持性能预算内并遵守隐私设置

**Given** 群备注与群内昵称
**When** 设置
**Then** 保存并可选择是否显示群昵称

## 测试（含安全负面测试）
- E2E：设置页各项
- 性能：成员列表分页
- 无障碍：开关读屏名称与状态
