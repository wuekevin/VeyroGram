# Story 20.5: 许可证、SBOM 与合规材料

**Epic 20：硬化与发布就绪（本 Story：Phase 7）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 合规负责人,
I want 汇总许可证清单、SBOM、NOTICE 与隐私/条款材料,
So that 许可证冲突与合规缺口清零.

## 验收标准（Acceptance Criteria）
**Given** 所有依赖
**When** 扫描
**Then** 无 UNLICENSED/未批准的 Custom 商业许可；@fancyapps/ui 已购买授权或替换

**Given** Manager/Web 无许可证风险
**When** 发布
**Then** 随发布留存用户的书面接受记录

**Given** 字体与素材
**When** 清点
**Then** 保留 OFL 署名与 Apache-2.0 NOTICE

## 测试（含安全负面测试）
- 扫描：license-checker/SBOM
- 审阅：NOTICE 完整性
- 法务：隐私政策与条款确认
