# Story 13.1: 已读未读与成员详情

**Epic 13：旗舰消息能力（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 消息显示已读未读标记，并查看已读/未读成员列表，可开关,
So that 知道对方是否看到了.

## 验收标准（Acceptance Criteria）
**Given** 关闭已读回执的成员
**When** 阅读消息
**Then** 不产生对其他人可见的已读状态，也不能反推

**Given** 大群
**When** 查看已读详情
**Then** 按成员上限分页，超限有降级说明

**Given** 已读详情
**When** 打开
**Then** 显示已读/未读/点赞成员及时间，仅包含已开启回执的成员

## 测试（含安全负面测试）
- 安全负面：隐私反推（通过差集推断）
- 性能：大群已读扇出压测
- E2E：开关与详情
