# Story 1.20: 管理面最小界面（登录、首页、审计）

**Epic 1：账号与最小聊天纵切（可信基座）（本 Story：Phase 2）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台所有者,
I want 在管理后台登录并查看审计日志,
So that 运营能看见并核对每一次管理动作.

## 验收标准（Acceptance Criteria）
**Given** 管理员
**When** 登录管理后台
**Then** 通过 MFA 后进入首页，显示基础概览

**Given** 审计页
**When** 查询
**Then** 只读展示审计日志并支持筛选

**Given** 每个后台页面
**When** 渲染
**Then** 具备加载、空、错误、无权限状态，键盘可达、焦点环可见

## 测试（含安全负面测试）
- E2E：登录-MFA-审计查看
- 无障碍：a11y_scan
- 视觉：后台基线
