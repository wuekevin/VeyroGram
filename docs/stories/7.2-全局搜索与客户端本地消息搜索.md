# Story 7.2: 全局搜索与客户端本地消息搜索

**Epic 7：会话列表、搜索与通知（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 搜索联系人、群、文件，并在本地已同步的聊天记录里搜索关键词,
So that 快速找回信息，且服务端不保存消息正文索引.

## 验收标准（Acceptance Criteria）
**Given** 搜索联系人/群
**When** 查询
**Then** 结果受成员资格与可见性约束（文件搜索由 10.3 启用）

**Given** 关键词搜索
**When** 在客户端执行
**Then** 仅搜索本地已同步历史，被撤回或无权限内容不出现

**Given** 服务端索引
**When** 未通过隐私评审
**Then** 不创建（ADR-0010）

**Given** 本地索引
**When** 用户登出或注销
**Then** 索引被擦除；索引在设备上加密存储且用户可手动清除

## 测试（含安全负面测试）
- 安全负面：被移出成员的搜索结果
- 性能：本地索引大小与耗时记录
- E2E：搜索结果跳转

| 列 | 任务 |

## 配置与回滚
- **配置/决策点：** 本地索引存储上限
- **回滚方案：** 关闭本地索引不影响聊天
