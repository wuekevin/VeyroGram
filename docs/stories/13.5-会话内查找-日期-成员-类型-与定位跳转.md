# Story 13.5: 会话内查找（日期/成员/类型）与定位跳转

**Epic 13：旗舰消息能力（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在会话内按日期、成员、类型查找历史（关键词在本地）,
So that 快速定位历史.

## 验收标准（Acceptance Criteria）
**Given** 按日期/成员/类型
**When** 查询
**Then** 通过 IM 消息同步与 MySQL 元数据，并按可见性过滤

**Given** 被移出成员或已撤回内容
**When** 查询
**Then** 不出现

**Given** 关键词
**When** 查询
**Then** 仅在本地已同步历史执行

**Given** 查找结果
**When** 点击
**Then** 跳转到原消息位置并高亮提醒

## 测试（含安全负面测试）
- 安全负面：越权查询历史
- E2E：三种过滤
- 性能：分页
