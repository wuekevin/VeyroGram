# Story 17.3: 自动风险扫描与恶意样本集

**Epic 17：小程序运行时与市场（本 Story：Phase 5）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 审核员,
I want 提交的包自动扫描域名、危险 API、敏感能力与依赖许可证,
So that 降低恶意小程序上架风险.

## 验收标准（Acceptance Criteria）
**Given** 恶意测试集
**When** 扫描
**Then** 全部被标记，报告随审核可见

**Given** 依赖许可证
**When** 扫描
**Then** 标出 UNLICENSED/Custom 商业许可

**Given** 误报
**When** 申诉
**Then** 有复核通道

## 测试（含安全负面测试）
- 安全负面：样本集拦截率 100%（OSM-2）
- 回归：规则版本化
- 性能：扫描耗时
