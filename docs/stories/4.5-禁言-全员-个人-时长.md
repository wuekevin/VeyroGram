# Story 4.5: 禁言（全员、个人、时长）

**Epic 4：群聊与高级群管理（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 群主/管理员,
I want 全员禁言或对个人设置禁言时长,
So that 维持群秩序.

## 验收标准（Acceptance Criteria）
**Given** 禁言期间
**When** 被禁言者发送
**Then** 在 IM 层（send_ban/before_send）被拒绝，界面显示剩余时长

**Given** 禁言到期
**When** 到期时间到达
**Then** 自动恢复且多设备一致

**Given** 管理员禁言管理员
**When** 角色不允许
**Then** 被拒绝

**Given** 点击成员头像
**When** 管理员
**Then** 可查看资料并单独设置禁言及时长

## 测试（含安全负面测试）
- 安全负面：绕过客户端直发被拒
- E2E：禁言与到期
- 时延：到期恢复误差记录
