# Story 17.4: 人工审核、申诉与上架

**Epic 17：小程序运行时与市场（本 Story：Phase 5）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 审核员,
I want 依据清单人工审核，开发者可申诉,
So that 把控质量与合规.

## 验收标准（Acceptance Criteria）
**Given** 审核
**When** 结论
**Then** 写审计并给出可操作的整改项

**Given** 申诉
**When** 提交
**Then** 由不同审核员处理

**Given** 审核通过
**When** 上架
**Then** 包签名并进入灰度

## 测试（含安全负面测试）
- 安全负面：越权审核
- E2E：提交-审核-驳回-申诉
- 审计：结论记录
