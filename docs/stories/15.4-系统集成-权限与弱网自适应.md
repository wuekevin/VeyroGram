# Story 15.4: 系统集成、权限与弱网自适应

**Epic 15：音视频通话与会议（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 通话遵守各平台来电与前后台规则，弱网自适应,
So that 体验自然.

## 验收标准（Acceptance Criteria）
**Given** 系统来电
**When** 与通话冲突
**Then** 按平台规则处理（挂起/保持）

**Given** 弱网
**When** 触发自适应
**Then** 分辨率/帧率逐级调整并显示提示

**Given** 权限
**When** 被拒
**Then** 引导到系统设置

## 测试（含安全负面测试）
- E2E：来电冲突
- 弱网：丢包 20%/抖动场景记录
- 合规：App Review 规则审查
