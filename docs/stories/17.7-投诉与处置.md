# Story 17.7: 投诉与处置

**Epic 17：小程序运行时与市场（本 Story：Phase 5）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台运营,
I want 受理用户与第三方对应用的投诉并处置，可申诉,
So that 平台责任与可追溯.

## 验收标准（Acceptance Criteria）
**Given** 投诉
**When** 受理
**Then** 处置包含警告、限权、下架、封禁主体，均写审计并可申诉

**Given** 封禁主体
**When** 生效
**Then** 其所有应用暂停并通知

**Given** 处置
**When** 复核
**Then** 可撤销并留痕

## 测试（含安全负面测试）
- 安全负面：越权处置
- E2E：投诉到处置
- 审计：全链路
