# Story 18.3: 开发者结算（条件项）

**Epic 18：订阅、权益与支付（本 Story：Phase 6）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 开发者,
I want 在决策与法务批准后结算收入,
So that 开发者生态变现.

## 验收标准（Acceptance Criteria）
**Given** 未获批准
**When** 访问
**Then** 不暴露任何收费入口

**Given** 获批
**When** 结算
**Then** 对账、发票/税务对接符合 FR-55 的幂等与审计要求

**Given** 争议
**When** 提交
**Then** 有处理流程

## 测试（含安全负面测试）
- 合规：法务审批记录
- 集成：沙箱结算
- 审计：结算全链路
