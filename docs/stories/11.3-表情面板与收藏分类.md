# Story 11.3: 表情面板与收藏分类

**Epic 11：小视频与表情商店（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在消息面板切换 Emoji、收藏、表情包并搜索,
So that 快速找到表情.

## 验收标准（Acceptance Criteria）
**Given** 表情面板
**When** 打开
**Then** 显示搜索入口、Emoji 分类、收藏分类（首项为“制作表情”）

**Given** 收藏分类
**When** 查看
**Then** 显示用户收藏的表情

**Given** 旧客户端
**When** 收到动图
**Then** 降级为静态图

## 测试（含安全负面测试）
- E2E：切换与搜索
- 兼容：动图降级
- 无障碍：面板读屏
