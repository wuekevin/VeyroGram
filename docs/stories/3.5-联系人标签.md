# Story 3.5: 联系人标签

**Epic 3：联系人与社交关系（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 创建、修改、删除标签并批量整理联系人,
So that 分组管理联系人.

## 验收标准（Acceptance Criteria）
**Given** 创建标签
**When** 选择联系人
**Then** 标签仅本人可见并跨设备同步

**Given** 批量打标签
**When** 超过数量上限
**Then** 返回明确错误

**Given** 越权读取他人标签
**When** 直接调用接口
**Then** 被拒绝

## 测试（含安全负面测试）
- 安全负面：标签 IDOR
- 性能：批量操作限速
- E2E：增删改标签
