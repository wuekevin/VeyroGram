# Story 14.2: 客服工作台、转接、快捷回复与工单

**Epic 14：客服系统（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 客服,
I want 处理会话、转接、使用快捷回复、创建工单，并设置欢迎词与查看访客资料,
So that 高效解决问题.

## 验收标准（Acceptance Criteria）
**Given** 转接
**When** 完成
**Then** 保留上下文与权限边界，跨技能组不泄露

**Given** 欢迎词
**When** 访客发消息
**Then** 自动发送客服欢迎词，并显示访客资料详情与用户标签

**Given** 创建工单
**When** 保存
**Then** 会话与工单关联并可追踪

**Given** 主管
**When** 需要
**Then** 可手动分配与改派会话并写审计

## 测试（含安全负面测试）
- 安全负面：转接越权
- E2E：转接/工单/快捷回复
- 无障碍：工作台键盘与读屏
- 安全负面：访客输入在工作台/工单/质检页的 XSS 与 HTML 注入
