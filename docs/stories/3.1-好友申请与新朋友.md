# Story 3.1: 好友申请与新朋友

**Epic 3：联系人与社交关系（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 发起、接受或拒绝好友申请，并在“新朋友”里看到状态,
So that 建立社交关系.

## 验收标准（Acceptance Criteria）
**Given** 发送好友申请
**When** 对方接受
**Then** 双向好友关系一致并生成打招呼系统消息

**Given** 新申请
**When** 到达
**Then** 通讯录显示红点并可处理

**Given** 重复或超限申请
**When** 提交
**Then** 返回统一错误（被拉黑的统一表现由 3.2 保证）

## 测试（含安全负面测试）
- 安全负面：批量加好友限频；被拉黑信息不泄露
- E2E：申请-接受-拒绝
- 回归：红点计数
