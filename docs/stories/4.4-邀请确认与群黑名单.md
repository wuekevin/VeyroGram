# Story 4.4: 邀请确认与群黑名单

**Epic 4：群聊与高级群管理（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 群主/管理员,
I want 开启邀请审核，并把成员加入群黑名单,
So that 控制谁能进群.

## 验收标准（Acceptance Criteria）
**Given** 开启邀请确认
**When** 成员邀请他人
**Then** 进入待审核并通知管理员，待审核有过期时间

**Given** 群黑名单成员
**When** 通过邀请或二维码入群
**Then** 被拒绝

**Given** 审核通过
**When** 完成
**Then** 生成系统消息并同步 IM 订阅

**Given** 群二维码
**When** 扫码入群
**Then** 遵守邀请确认设置与群黑名单

**Given** 邀请
**When** 对方已被邀请人拉黑
**Then** 被拒绝（沿用 3.2 黑名单服务）

## 测试（含安全负面测试）
- 安全负面：黑名单成员重入
- E2E：邀请-审核-入群
- 集成：IM 黑名单同步
