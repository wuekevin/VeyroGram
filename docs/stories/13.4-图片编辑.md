# Story 13.4: 图片编辑

**Epic 13：旗舰消息能力（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 发送图片前涂鸦、裁剪、加文字、加滤镜,
So that 发送前完成简单处理.

## 验收标准（Acceptance Criteria）
**Given** 编辑图片
**When** 涂鸦/裁剪/文字/滤镜
**Then** 在本地完成并可撤销

**Given** 发送
**When** 选择移除位置元数据
**Then** EXIF 位置被剥离

**Given** 低端设备
**When** 编辑大图
**Then** 有降采样与内存保护

**Given** 上传的图片
**When** 服务端处理
**Then** 服务端也剥离 EXIF 位置等元数据

## 测试（含安全负面测试）
- E2E：编辑并发送
- 安全：EXIF 剥离验证
- 性能：低端设备内存
