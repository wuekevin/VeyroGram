# Story 11.1: 小视频录制、选择与上传

**Epic 11：小视频与表情商店（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 录制 15 秒（可配置）或选择相册视频并发送,
So that 更丰富的表达.

## 验收标准（Acceptance Criteria）
**Given** 录制
**When** 达到上限
**Then** 自动停止并预览，显示大小

**Given** 上传
**When** 进行
**Then** 显示进度，失败可重试

**Given** 权限被拒
**When** 进入
**Then** 给出引导

## 测试（含安全负面测试）
- E2E：录制/选择/重试
- 安全负面：超限/非视频文件被拒
- 性能：上传耗时
