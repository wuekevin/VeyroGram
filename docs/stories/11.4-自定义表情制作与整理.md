# Story 11.4: 自定义表情制作与整理

**Epic 11：小视频与表情商店（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 从相册制作表情并排序、删除,
So that 个性化表达.

## 验收标准（Acceptance Criteria）
**Given** 选择图片
**When** 保存制作
**Then** 自定义表情需经内容审核后才可被他人使用

**Given** 整理
**When** 排序或删除
**Then** 多设备同步，提供非拖拽的上移/下移替代控件

**Given** 违规表情
**When** 下架
**Then** 对所有人立即不可见

## 测试（含安全负面测试）
- 安全负面：恶意图片审核
- E2E：制作-排序-删除
- 无障碍：排序替代控件（WCAG 2.5.1）
