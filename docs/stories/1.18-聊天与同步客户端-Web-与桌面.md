# Story 1.18: 聊天与同步客户端：Web 与桌面

**Epic 1：账号与最小聊天纵切（可信基座）（本 Story：Phase 2）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在 Web 与桌面上收发单聊消息并离线同步,
So that 桌面与网页聊天纵切可用.

## 验收标准（Acceptance Criteria）
**Given** 两台设备
**When** 一端发送文本
**Then** 另一端按序收到，重试不重复，失败显示重试入口

**Given** 离线后重连
**When** 同步
**Then** 消息、未读与草稿补齐

**Given** 聊天页
**When** 键盘与读屏
**Then** 消息列表为 log 区域、发送与重试可操作

## 测试（含安全负面测试）
- E2E：Web 与桌面收发、离线恢复
- 无障碍：读屏与键盘
- 安全负面：Electron IPC/外链检查

## 配置与回滚
- **配置/决策点：** before_send 超时预算（P95 ≤50 ms，待测）与 fail-closed 规则类
- **回滚方案：** 关闭 before_send 即退回 IM 原生规则；不影响已存消息
