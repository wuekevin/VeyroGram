# Story 7.6: 国内厂商推送通道与 Web Push

**Epic 7：会话列表、搜索与通知（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在华为、小米、OPPO、VIVO 手机和浏览器上收到通知,
So that 国内 Android 设备也能可靠收到消息.

## 验收标准（Acceptance Criteria）
**Given** 厂商设备
**When** 注册
**Then** 使用对应厂商通道，密钥通过受保护配置注入，不入源码

**Given** 通道不可用
**When** 发送
**Then** 回退到 FCM 或应用内同步并记录失败率

**Given** 浏览器
**When** 用户授权
**Then** 支持 Web Push，内容可脱敏

## 测试（含安全负面测试）
- 集成：各厂商沙箱推送
- 安全负面：密钥扫描、令牌跨用户
- 监控：分通道成功率
