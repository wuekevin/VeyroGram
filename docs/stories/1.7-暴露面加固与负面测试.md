# Story 1.7: 暴露面加固与负面测试

**Epic 1：账号与最小聊天纵切（可信基座）（本 Story：Phase 2）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台所有者,
I want WuKongIM 与其他内部端口对公网与非白名单来源不可达，默认密钥全部覆盖,
So that 堵住无鉴权发信/改令牌的攻击面（R-21）.

## 验收标准（Acceptance Criteria）
**Given** 生产部署
**When** 从公网、同网段非白名单主机访问 5001/5301/7001/9099/pprof/MQTT
**Then** 全部不可达

**Given** WuKongIM 默认配置
**When** 部署校验运行
**Then** 覆盖 cluster.join_token、manager 用户与 jwt_secret、bench.api_token，并关闭插件热加载与 MQTT

**Given** 部署校验
**When** 在 CI 与预发运行
**Then** 暴露面扫描（外部+内网）为必过门禁，任何可达的内部端口即失败

## 测试（含安全负面测试）
- 安全负面：暴露面扫描脚本（外部+内网）全部失败才算通过

- 门禁：已接入 `tools/ci_local.sh` 与 CI 的 infra 任务（拉取固定 SHA 的 WuKongIM 并运行真实二进制测试）。
