# Story 2.7: 清空聊天记录与保留策略

**Epic 2：完整的消息体验（本 Story：Phase 3）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 清空本地会话记录，管理员按审批清理远程记录,
So that 隐私可控且合规可审计.

## 验收标准（Acceptance Criteria）
**Given** 用户清空会话
**When** 确认
**Then** 服务端记录该用户的 cleared_before_seq，多设备同步隐藏历史（保留上游“清空聊天记录”语义，仅影响本人可见范围），其他成员不受影响

**Given** WuKongIM 无单条物理删除接口
**When** 需要物理清理
**Then** 能力边界写入文档：用墓碑/内容替换实现，物理清理走 9.1 的审批流程

**Given** 保留期到期
**When** worker 运行
**Then** 按策略清理且清理动作可审计

## 测试（含安全负面测试）
- 安全负面：普通用户无法清理他人记录
- 集成：保留期清理 worker
- E2E：清空后多端同步

## 配置与回滚
- **配置/决策点：** 保留期（OQ-4 待法务）；决策：恢复用户侧“清空”语义，管理员物理清理另需审批（见 9.1）
- **回滚方案：** 清理不可逆，需二次确认与审批
