# Story 5.4: 密码设置与重设

**Epic 5：个人资料、隐私与账号安全（本 Story：Phase 4）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 设置登录密码并通过验证码重设,
So that 多一种登录与找回方式.

## 验收标准（Acceptance Criteria）
**Given** 设置密码
**When** 保存
**Then** 以 Argon2id 存储

**Given** 验证码重设
**When** 完成
**Then** 其他设备会话全部失效

**Given** 连续失败
**When** 达阈值
**Then** 延迟与设备风控

## 测试（含安全负面测试）
- 安全负面：弱哈希检测、撞库限频
- E2E：重设后旧设备失效
- 单元：KDF 参数
