# Story 16.6: Webhook、沙箱与调试日志

**Epic 16：开放平台基础（本 Story：Phase 5）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 开发者,
I want 订阅事件并在沙箱里调试，失败可重放,
So that 可靠的事件集成.

## 验收标准（Acceptance Criteria）
**Given** Webhook
**When** 投递
**Then** 带 HMAC-SHA256(timestamp.body)、时间戳窗口，失败指数退避后入死信并可手动重放

**Given** 沙箱
**When** 使用
**Then** 沙箱令牌无法访问生产数据

**Given** 调试日志
**When** 查看
**Then** 脱敏且不含令牌与完整手机号

**Given** Webhook 回调 URL
**When** 注册或投递
**Then** 禁止内网、回环、链路本地地址，并防 DNS 重绑定（投递时重新解析并校验）

## 测试（含安全负面测试）
- 安全负面：重放、篡改、过期时间戳
- 集成：死信重放
- E2E：订阅-投递-重放
- 安全负面：Webhook SSRF（内网、元数据地址、DNS 重绑定）
