# Story 16.2: 团队与角色

**Epic 16：开放平台基础（本 Story：Phase 5）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 开发者,
I want 邀请团队成员并分配所有者/管理员/开发者/只读角色,
So that 多人协作开发.

## 验收标准（Acceptance Criteria）
**Given** 角色
**When** 调用写接口
**Then** 只读成员返回 403

**Given** 转让所有者
**When** 提交
**Then** 需二次验证

**Given** 角色变更
**When** 完成
**Then** 写审计

## 测试（含安全负面测试）
- 安全负面：角色越权矩阵
- E2E：邀请与转让
- 审计：变更记录
