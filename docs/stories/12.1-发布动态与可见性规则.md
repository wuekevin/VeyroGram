# Story 12.1: 发布动态与可见性规则

**Epic 12：朋友圈（动态）（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 发布文本/最多 9 图/单视频，选择位置、提醒谁看，并设置可见性,
So that 分享生活且可控范围.

## 验收标准（Acceptance Criteria）
**Given** 发布
**When** 选择可见性（公开/私有/部分可见/不给谁看）并从通讯录或标签选人
**Then** 规则按当前好友与标签关系计算

**Given** 被排除者
**When** 通过 ID 直接访问动态、点赞、评论、媒体 URL
**Then** 全部被拒绝

**Given** 9 图
**When** 排序
**Then** 可拖拽也可用前移/后移按钮；上传显示进度与结果

**Given** 黑名单关系
**When** 计算可见性
**Then** 同步生效（沿用 3.2 黑名单服务）

## 测试（含安全负面测试）
- 安全负面：可见性越权矩阵（T-05）
- E2E：四种可见性
- 无障碍：排序替代控件与读屏
