# Story 2.5: 引用、转发、合并转发与删除范围

**Epic 2：完整的消息体验（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 引用回复，逐条或合并转发，选择仅自己删除或双方删除,
So that 更高效地整理与分享沟通.

## 验收标准（Acceptance Criteria）
**Given** 转发人无权访问原消息
**When** 转发
**Then** 被拒绝，合并转发中的原消息权限独立校验

**Given** 选择“对所有人删除”
**When** 超出时限或角色不允许
**Then** 被拒绝并写审计

**Given** 引用消息
**When** 原消息被撤回
**Then** 引用块显示“已撤回”而不泄露原文

## 测试（含安全负面测试）
- 安全负面：越权转发与引用泄露
- E2E：合并转发多端展示
- 回归：删除范围
