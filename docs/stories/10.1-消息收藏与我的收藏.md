# Story 10.1: 消息收藏与我的收藏

**Epic 10：收藏、位置与文件（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 收藏文本/图片消息，管理我的收藏并转发给朋友,
So that 保存重要信息.

## 验收标准（Acceptance Criteria）
**Given** 消息菜单
**When** 收藏
**Then** 进入我的收藏，含作者、昵称、收藏时间

**Given** 收藏列表
**When** 复制文本、缩放图片、转发给朋友、删除
**Then** 各操作可用且跨设备同步

**Given** 源消息被撤回
**When** 查看收藏副本
**Then** 按策略保留或标记且有书面说明

**Given** 收藏删除
**When** 同步
**Then** 多设备在 10 秒内一致 [目标值待测]

## 测试（含安全负面测试）
- 安全负面：他人不能读取我的收藏
- E2E：收藏-转发-删除
- 性能：同步删除传播时延
