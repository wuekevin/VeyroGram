# Story 4.3: 群角色与权限

**Epic 4：群聊与高级群管理（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 群主,
I want 指派和撤销管理员，所有群管理动作由服务端校验,
So that 分担群管理.

## 验收标准（Acceptance Criteria）
**Given** 绕过客户端直接调用群管理接口
**When** 非群主/管理员
**Then** 被拒绝并写审计

**Given** 转让群主
**When** 确认
**Then** 需二次确认并通知全体管理员

**Given** 角色变更
**When** 完成
**Then** 权限在 IM 与业务两侧一致

**Given** 群头像设置
**When** 群主或管理员修改
**Then** 校验权限并经内容审核（9.3）后生效

## 测试（含安全负面测试）
- 安全负面：群管理越权矩阵
- E2E：指派与转让
- 一致性：IM 与业务权限同步
