# Story 7.5: 通知偏好与多设备去重

**Epic 7：会话列表、搜索与通知（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 设置免打扰与通知偏好，在一台设备已读后其他设备清除通知,
So that 通知不打扰也不重复.

## 验收标准（Acceptance Criteria）
**Given** 免打扰
**When** 收到消息
**Then** 不推送，但 @ 强提醒按偏好

**Given** 多设备
**When** 其中一台已读
**Then** 其他设备清除对应通知

**Given** 静默推送
**When** 到达
**Then** 仅更新角标与同步

## 测试（含安全负面测试）
- E2E：多设备去重
- 回归：偏好优先级
- 安全负面：他人不可修改偏好
