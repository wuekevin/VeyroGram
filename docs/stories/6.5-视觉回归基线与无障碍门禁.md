# Story 6.5: 视觉回归基线与无障碍门禁

**Epic 6：统一品牌与设计系统落地（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 工程团队,
I want 截图基线与无障碍自动化检查进入 CI,
So that 设计不被后续改动悄悄破坏.

## 验收标准（Acceptance Criteria）
**Given** 关键屏幕
**When** CI 运行
**Then** 与 360/390 手机、平板、桌面、明暗、中英、200% 字号基线比对

**Given** 页面
**When** 运行 a11y_scan
**Then** axe、键盘焦点、目标尺寸、裁切、回流检查全部通过

**Given** 新增界面
**When** 提交
**Then** 必须附 WCAG 清单对应条目的证据

## 测试（含安全负面测试）
- 自动：基线对比与 a11y 扫描
- 人工：读屏与键盘记录（ACCESSIBILITY-REVIEW-GUIDE）
- 回归：基线更新需评审
