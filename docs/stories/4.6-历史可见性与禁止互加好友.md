# Story 4.6: 历史可见性与禁止互加好友

**Epic 4：群聊与高级群管理（本 Story：Phase 4）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 群主,
I want 控制新成员能否看到入群前历史，并禁止群内互加好友,
So that 保护群内信息与隐私.

## 验收标准（Acceptance Criteria）
**Given** 关闭历史可见
**When** 新成员拉取历史
**Then** 通过任何接口都取不到入群前消息

**Given** 开启禁止互加好友
**When** 从群发起好友申请
**Then** 入口隐藏且服务端拒绝

**Given** 切换设置
**When** 保存
**Then** 即时生效并写审计

## 测试（含安全负面测试）
- 安全负面：历史越权拉取（含搜索、同步）
- E2E：开关切换
- 回归：可见起点字段 history_visible_from
