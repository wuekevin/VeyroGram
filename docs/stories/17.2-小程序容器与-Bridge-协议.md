# Story 17.2: 小程序容器与 Bridge 协议

**Epic 17：小程序运行时与市场（本 Story：Phase 5）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在宿主绘制顶栏与授权弹窗的受限容器里使用小程序，Bridge 调用安全可控,
So that 安全地使用第三方小程序.

## 验收标准（Acceptance Criteria）
**Given** Bridge 调用
**When** 缺 nonce、签名或能力未声明
**Then** fail-closed，重放同一 nonce 被拒

**Given** 敏感能力（位置、相机、文件、剪贴板、分享）
**When** 使用
**Then** 每次由宿主弹窗并由用户显式授权

**Given** 能力探测
**When** 旧容器遇新能力
**Then** 返回“不支持”而非崩溃

**Given** 小程序运行
**When** 网络与资源
**Then** 网络与导航受域名白名单限制，应用 CSP 生效，内存与资源有上限，存储/Cookie 按应用分区

## 测试（含安全负面测试）
- 安全负面：恶意小程序测试集（XSS、越权 Bridge、SSRF、剪贴板窃取）为上线硬门槛
- 合约：Bridge SDK 契约测试
- E2E：四端运行同一示例
