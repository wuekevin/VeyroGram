# Story 11.2: 小视频转码、封面、播放与转发

**Epic 11：小视频与表情商店（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 视频自动转码并生成封面，可播放、保存、转发,
So that 各端都能顺畅观看.

## 验收标准（Acceptance Criteria）
**Given** 视频上传
**When** 转码
**Then** 生成封面与适配码率，失败时发送者看到可重试状态

**Given** 未下载视频
**When** 点击
**Then** 显示下载进度后播放

**Given** 编解码
**When** 上线
**Then** 许可与版权在 license-and-ip 登记（OQ-6）

**Given** 会话媒体中心
**When** 有视频
**Then** 视频接入 7.3 的媒体中心

## 测试（含安全负面测试）
- 集成：转码沙箱与失败重试
- 安全负面：恶意视频文件隔离
- 性能：转码队列时延

## 跨端任务
| 列 | 任务 |
|---|---|
| Server | 转码 worker（沙箱） |
| Android | 播放与保存 |
| iOS | 播放与保存 |
| Web | 播放与保存 |
| Desktop | 播放与保存 |
| Manager | 不适用：不涉及管理后台 |
| API | /v1/videos |
| DB | video_asset 状态 |
| 通知 | 不适用：不触发通知 |
| 权限 | 下载签名 URL |
| E2E | 转码 E2E |

## 配置与回滚
- **配置/决策点：** 转码方案与编解码许可（OQ-6）
- **回滚方案：** 转码失败不影响原文件存储
