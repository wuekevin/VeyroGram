# Story 15.2: 一对一音视频通话

**Epic 15：音视频通话与会议（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 发起和接听音视频通话，前后台切换与断网重连,
So that 随时语音视频沟通.

## 验收标准（Acceptance Criteria）
**Given** 通话中切后台
**When** 返回
**Then** 通话保持或按平台规则恢复

**Given** 断网
**When** 恢复
**Then** 自动重连

**Given** 摄像头麦克风权限被拒
**When** 通话
**Then** 提供引导而非静默失败

**Given** 后台或锁屏
**When** 来电
**Then** iOS 使用 VoIP 推送 + CallKit，Android 使用全屏意图 + ConnectionService（依赖 Apple 账号主体，OQ-5）

## 测试（含安全负面测试）
- E2E：重连与权限
- 弱网：质量降级而不掉线
- 无障碍：通话控制的读屏
