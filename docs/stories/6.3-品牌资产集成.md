# Story 6.3: 品牌资产集成

**Epic 6：统一品牌与设计系统落地（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 客户端开发者,
I want 各端集成启动页、应用图标、通知图标与官网资产,
So that 品牌从第一眼开始一致.

## 验收标准（Acceptance Criteria）
**Given** Android
**When** 构建
**Then** 使用自适应图标三层、启动图标、状态栏通知图标

**Given** iOS
**When** 构建
**Then** 使用不透明 1024 图标及暗色/着色变体，并在真机验证着色

**Given** Web/PWA/桌面
**When** 构建
**Then** 使用 favicon、maskable、ICO/ICNS 与托盘图标

**Given** 矢量资产
**When** 生成
**Then** 由 SVG 源导出，禁止用位图放大冒充矢量

## 测试（含安全负面测试）
- 视觉：各平台图标截图审阅
- 合规：商标近似检索结果存档（PRD OQ-1）
- 回归：资产构建可重现
