# Story 6.2: 原创图标库与 Emoji 门禁

**Epic 6：统一品牌与设计系统落地（本 Story：Phase 3）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 客户端开发者,
I want 导航、工具栏、Tab、后台菜单只用原创 SVG 图标库，并由门禁阻断 Emoji,
So that 品牌一致且满足“菜单不得用 Emoji”约束.

## 验收标准（Acceptance Criteria）
**Given** 图标库
**When** 构建
**Then** 生成单文件、雪碧图、选中态与 icons.json（中英文无障碍名称）

**Given** 导航源码含 Emoji
**When** 运行 tools/lint_no_emoji_nav.py
**Then** 退出码 1（含 router 与 menu 定义行）

**Given** 聊天内容与表情包数据
**When** 含 Emoji
**Then** 不受限制

## 测试（含安全负面测试）
- 单元：lint 正反用例（含 ⏎ 不误报）
- 视觉：明暗背景图标一致性
- 无障碍：每个图标有名称
