# Story 5.6: 账号注销与数据导出

**Epic 5：个人资料、隐私与账号安全（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 注销账号并申请导出我的数据,
So that 掌控自己的数据.

## 验收标准（Acceptance Criteria）
**Given** 通过验证码注销
**When** 完成
**Then** 个人资料与好友关系销毁或匿名化，保留项在隐私政策列明

**Given** 导出申请
**When** worker 完成
**Then** 产物受签名下载保护且有过期时间

**Given** 注销后
**When** 他人访问
**Then** 不返回已注销用户的可识别资料

**Given** 已注销用户
**When** 他人尝试拉入群或搜索
**Then** 不可被拉入群并提示“该用户已注销”，搜索不返回

## 测试（含安全负面测试）
- 安全负面：未验证不能注销；导出文件越权下载
- E2E：注销与导出
- 合规：保留项清单与实际一致
- 安全负面：已注销用户的令牌、搜索与群关系全部失效
