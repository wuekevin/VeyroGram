# Story 15.3: 群通话、会议与屏幕共享

**Epic 15：音视频通话与会议（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在群里发起会议，多人入会，桌面端共享屏幕,
So that 多人协作.

## 验收标准（Acceptance Criteria）
**Given** 弱网
**When** 会议中
**Then** 优先降低视频质量保音频，恢复后自动重连

**Given** 录制
**When** 发起
**Then** 默认关闭，开启需所有参与者明确同意并有可见标识

**Given** 屏幕共享
**When** 桌面端发起
**Then** 需系统权限并显示共享中标识

## 测试（含安全负面测试）
- E2E：多人会议与重连
- 安全负面：未同意的录制
- 性能：SFU 并发
