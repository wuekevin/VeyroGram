# Story 19.3: 官网访客客服入口与匿名访客认证

**Epic 19：官网、下载与客户端更新（本 Story：Phase 6）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 访客,
I want 在官网无需登录即可咨询客服，访客身份单独认证并受限,
So that 未注册用户也能获得帮助而不扩大攻击面.

## 验收标准（Acceptance Criteria）
**Given** 匿名访客
**When** 发起咨询
**Then** 获得短期、仅限客服会话范围的访客令牌，不能访问任何用户 API

**Given** 访客滥用
**When** 超限
**Then** 按 IP/指纹限频并可封禁

**Given** 访客资料
**When** 客服查看
**Then** 仅展示最小字段并受保留策略约束

## 测试（含安全负面测试）
- 安全负面：访客令牌越权、会话枚举、XSS
- E2E：官网咨询到分配
- 合规：访客数据保留（OQ-4）
