# Story 13.3: 消息点赞与在线状态

**Epic 13：旗舰消息能力（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 给消息点赞并查看点赞列表，查看对方在线状态与最近在线,
So that 更轻量的互动与临场感.

## 验收标准（Acceptance Criteria）
**Given** 点赞
**When** 长按消息
**Then** 显示点赞内容与点赞列表

**Given** 在线状态
**When** 对方关闭展示
**Then** 不泄露在线与最近在线

**Given** 在线状态
**When** 单聊与会话列表
**Then** 一小时内显示时长，群聊显示在线人数

## 测试（含安全负面测试）
- 安全负面：隐私设置绕过
- E2E：点赞与在线状态
- 性能：presence 查询
