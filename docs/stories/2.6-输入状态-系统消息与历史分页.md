# Story 2.6: 输入状态、系统消息与历史分页

**Epic 2：完整的消息体验（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 看到对方正在输入、系统通知，并分页浏览历史,
So that 会话更有临场感且历史可追溯.

## 验收标准（Acceptance Criteria）
**Given** 对方正在输入
**When** 单聊
**Then** 在会话中显示输入提示，隐私设置关闭时不发送

**Given** 群/单聊系统事件
**When** 发生
**Then** 生成系统消息（创建群、邀请、改名、加好友打招呼等）

**Given** 下拉历史
**When** 分页
**Then** 按序加载，不出现已无权限的消息

**Given** 向非好友发送消息
**When** 发送
**Then** 会话中提示需要先加好友或对方设置了限制（统一措辞，不泄露拉黑）

## 测试（含安全负面测试）
- E2E：输入提示与隐私开关
- 安全负面：被移出成员的历史拉取被拒
- 回归：系统消息文案中英
