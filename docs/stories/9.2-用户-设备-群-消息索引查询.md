# Story 9.2: 用户/设备/群/消息索引查询

**Epic 9：管理后台商业运营能力（本 Story：Phase 3）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 平台运营,
I want 在受限条件下按用户、设备、群、消息索引查询,
So that 处理问题所需的最小可见.

## 验收标准（Acceptance Criteria）
**Given** 查询敏感信息
**When** 提交
**Then** 默认脱敏，查看明文或聊天记录需理由并留痕

**Given** 导出
**When** 发起
**Then** 需审批

**Given** 查询聊天内容
**When** 目标会话
**Then** 仅在授权范围内且遵守保留策略

## 测试（含安全负面测试）
- 安全负面：未填理由不可查看；越权查询
- 审计：每次明文访问有记录
- 性能：索引查询
