# Story 5.2: 隐私设置

**Epic 5：个人资料、隐私与账号安全（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 控制手机号/短号可搜索、在线状态、已读回执展示,
So that 隐私可控.

## 验收标准（Acceptance Criteria）
**Given** 关闭已读回执
**When** 保存
**Then** 偏好服务端强制并多设备同步，13.1 的已读详情与回执消费该偏好

**Given** 仅联系人可见在线状态
**When** 非联系人查询
**Then** 不泄露

**Given** 修改设置
**When** 保存
**Then** 服务端强制并多设备同步

## 测试（含安全负面测试）
- 安全负面：客户端绕过隐私设置被服务端拒绝
- E2E：开关多端同步
- 回归：隐私默认值
