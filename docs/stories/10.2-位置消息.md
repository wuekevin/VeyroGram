# Story 10.2: 位置消息

**Epic 10：收藏、位置与文件（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 发送当前位置或搜索选点，对方查看位置卡片并跳转地图,
So that 快速分享位置.

## 验收标准（Acceptance Criteria）
**Given** 发送位置
**When** 选择当前位置或搜索地点
**Then** 仅在用户操作时申请前台定位，不后台定位

**Given** 位置卡片
**When** 对方查看
**Then** 显示截图缩略图并可跳转地图

**Given** 缺少地图 Provider 密钥
**When** 入口
**Then** 隐藏而非崩溃

## 测试（含安全负面测试）
- 安全负面：位置权限最小化与拒绝路径
- E2E：发送与查看
- 合规：地图服务商条款（OQ-2）
- 安全负面：位置权限最小化，禁止后台定位；伪造位置不影响他人权限
