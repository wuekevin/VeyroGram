# Story 4.7: 撤回成员消息与群管理审计

**Epic 4：群聊与高级群管理（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 群主/管理员,
I want 撤回成员违规消息，并能查询管理操作记录,
So that 处置违规且可追溯.

## 验收标准（Acceptance Criteria）
**Given** 管理员撤回成员消息
**When** 完成
**Then** 在线成员 5 秒内收到撤回提示 [目标值待测]，离线设备重连后一致

**Given** 管理操作
**When** 发生
**Then** 审计记录含操作者、对象、时间、原因，普通管理员不可删除

**Given** 撤回后
**When** 他人搜索或下载
**Then** 原内容不可得

## 测试（含安全负面测试）
- 安全负面：撤回后读取路径
- 审计：不可篡改与链头校验
- 性能：大群撤回扩散时延记录
