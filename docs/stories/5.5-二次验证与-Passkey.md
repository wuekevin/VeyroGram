# Story 5.5: 二次验证与 Passkey

**Epic 5：个人资料、隐私与账号安全（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 启用 TOTP 或 Passkey 作为二次验证,
So that 更强的账号保护.

## 验收标准（Acceptance Criteria）
**Given** 启用二次验证
**When** 改密、注销或关闭设备锁
**Then** 必须二次验证

**Given** 丢失因子
**When** 走恢复流程
**Then** 书面化流程不能绕过设备锁

**Given** Passkey
**When** 登录
**Then** 使用 WebAuthn 并绑定设备

## 测试（含安全负面测试）
- 安全负面：恢复流程绕过尝试
- E2E：TOTP 与 Passkey
- 兼容：各端 WebAuthn 支持矩阵
