# Story 19.2: 客户端更新与灰度

**Epic 19：官网、下载与客户端更新（本 Story：Phase 6）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 应用检查更新，支持强制/可选更新与灰度，桌面更新有签名校验,
So that 安全及时地升级.

## 验收标准（Acceptance Criteria）
**Given** 更新包签名不匹配
**When** 安装
**Then** 被拒绝

**Given** 强制更新
**When** 触发
**Then** 提供过渡窗口与说明

**Given** 灰度
**When** 配置比例
**Then** 仅命中设备收到更新并可回滚

## 测试（含安全负面测试）
- 安全负面：恶意更新包
- E2E：灰度与回滚
- 合规：商店规则（OQ-5）
- 安全负面：降级攻击（回退到有漏洞的旧版本）被拒绝
