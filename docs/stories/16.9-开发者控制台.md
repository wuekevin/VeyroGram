# Story 16.9: 开发者控制台

**Epic 16：开放平台基础（本 Story：Phase 5）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 开发者,
I want 在控制台管理应用、密钥、授权、版本与团队,
So that 集中完成接入与运营.

## 验收标准（Acceptance Criteria）
**Given** 控制台每页
**When** 渲染
**Then** 具备加载/空/错误/无权限状态，密钥展示块一次性展示并可复制

**Given** 控制台
**When** 键盘与读屏
**Then** 可完成全部操作

**Given** 页面
**When** 1024–1440 宽
**Then** 无横向滚动

## 测试（含安全负面测试）
- 视觉回归与 a11y 扫描
- E2E：控制台核心流程
- 安全负面：越权访问他人应用
