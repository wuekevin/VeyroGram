# Story 13.2: 消息编辑与版本

**Epic 13：旗舰消息能力（本 Story：Phase 4）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 编辑已发送的消息并显示“已编辑”，保留版本策略,
So that 纠正错误而不丢失上下文.

## 验收标准（Acceptance Criteria）
**Given** 编辑
**When** 在时限内保存
**Then** 所有设备含离线设备最终一致，界面标注“已编辑”

**Given** 版本策略
**When** 配置
**Then** 保留全部版本或仅最新（可配置）

**Given** 被撤回消息
**When** 尝试编辑
**Then** 被拒绝

## 测试（含安全负面测试）
- 一致性：离线设备重连
- 安全负面：越权编辑他人消息
- E2E：编辑多端
