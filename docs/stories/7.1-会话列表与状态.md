# Story 7.1: 会话列表与状态

**Epic 7：会话列表、搜索与通知（本 Story：Phase 3）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 会话列表显示头像、时间、预览、红点、置顶、免打扰、发送状态与网络状态,
So that 快速掌握所有会话.

## 验收标准（Acceptance Criteria）
**Given** 未读超过 100
**When** 显示
**Then** 红点显示 99+，免打扰会话以图标而非仅变灰表示

**Given** 草稿
**When** 在会话列表
**Then** 显示草稿标记并跨设备同步

**Given** 无网络或未连接
**When** 打开
**Then** 顶部显示离线条与队列中的发送

**Given** 长按会话
**When** 菜单
**Then** 提供置顶、免打扰、删除聊天；置顶与免打扰跨设备同步

**Given** 基础在线状态
**When** 单聊与群聊
**Then** 单聊显示在线或一小时内最近在线时长，群标题显示总人数与在线人数（遵守隐私默认；13.3 提供隐私控制与细化）

**Given** 官方/系统账号
**When** 出现在会话
**Then** 显示官方标识（账号实体由 9.4 配置）

**Given** 置顶或免打扰变更
**When** 保存
**Then** 在其他设备 5 秒内一致 [目标值待测]

## 测试（含安全负面测试）
- E2E：置顶/免打扰/红点
- 视觉回归：列表在明暗/中英/200% 字号
- 无障碍：读屏朗读名称、末条、时间、未读与置顶状态
