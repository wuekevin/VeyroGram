# Story 8.3: 恶意链接与危险文件检测

**Epic 8：举报、内容安全与风控（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 消息里的恶意链接与危险文件被检测并标记,
So that 降低钓鱼与恶意软件风险.

## 验收标准（Acceptance Criteria）
**Given** 链接
**When** 命中恶意库
**Then** 显示风险提示或拦截

**Given** 扫描适配器
**When** 提供接口
**Then** 10.3 与 11.2 复用它；用测试夹具验证危险扩展名与魔数不符会被判隔离（上传入口在 10.3）

**Given** 扫描引擎不可用
**When** 上传
**Then** 文件保持“待检”不默认放行

## 测试（含安全负面测试）
- 安全负面：恶意样本集
- 集成：扫描服务不可用场景
- 性能：扫描耗时
