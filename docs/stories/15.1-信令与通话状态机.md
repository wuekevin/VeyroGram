# Story 15.1: 信令与通话状态机

**Epic 15：音视频通话与会议（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 通话有统一的状态机：响铃、接通、结束、忙线、超时、未接,
So that 各种异常都有明确结果.

## 验收标准（Acceptance Criteria）
**Given** 对方忙线、无应答、拒绝
**When** 发生
**Then** 双方显示明确状态并生成通话记录

**Given** 通话令牌/TURN 凭据
**When** 签发
**Then** 由服务端按次短时签发，不写死在客户端

**Given** 信令
**When** 经业务服务
**Then** 鉴权并校验会话成员资格

**Given** 通话记录
**When** 生成
**Then** 使用已登记的通话记录消息类型（2.1），各端渲染与降级一致

## 测试（含安全负面测试）
- 安全负面：伪造信令、越权拨打
- 状态机：全迁移测试
- E2E：忙线/超时/拒绝
- 安全负面：骚扰性频繁拨号限频；跨会话拨号越权
