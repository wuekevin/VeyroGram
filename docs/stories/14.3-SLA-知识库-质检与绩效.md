# Story 14.3: SLA、知识库、质检与绩效

**Epic 14：客服系统（本 Story：Phase 4）** · 规模 L（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 客服主管,
I want 监控 SLA，维护知识库，抽检质检并查看绩效,
So that 提升服务质量.

## 验收标准（Acceptance Criteria）
**Given** SLA 临界
**When** 接近超时
**Then** 主管收到提醒并可介入

**Given** 质检与导出
**When** 操作
**Then** 写审计，客服只能访问其技能组范围

**Given** 绩效报表
**When** 导出
**Then** 脱敏且需审批

## 测试（含安全负面测试）
- 安全负面：质检越权；导出泄露
- 指标：SLA 计时准确性
- E2E：质检流
