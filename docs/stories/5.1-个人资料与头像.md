# Story 5.1: 个人资料与头像

**Epic 5：个人资料、隐私与账号安全（本 Story：Phase 3）** · 规模 S（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 编辑头像、昵称、签名等资料,
So that 展示自己.

## 验收标准（Acceptance Criteria）
**Given** 编辑资料
**When** 保存
**Then** 多设备同步，头像格式与大小经校验

**Given** 他人查看
**When** 访问
**Then** 仅返回对其可见的字段

**Given** 头像文件
**When** 上传
**Then** 校验魔数、格式与大小；违规内容的审核由 9.3 处理

**Given** 平台短号
**When** 修改
**Then** 只允许修改一次

## 测试（含安全负面测试）
- 安全负面：不可见字段泄露
- E2E：资料同步
- 安全：头像文件校验（魔数）
