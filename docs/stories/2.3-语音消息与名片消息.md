# Story 2.3: 语音消息与名片消息

**Epic 2：完整的消息体验（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 长按录制语音并发送，分享联系人名片,
So that 更自然的沟通方式.

## 验收标准（Acceptance Criteria）
**Given** 长按录音
**When** 松手
**Then** 发送并显示时长；上滑取消不发送；权限被拒有引导

**Given** 选择联系人
**When** 发送名片
**Then** 接收方可查看资料并发起添加

**Given** 语音消息
**When** 播放
**Then** 显示进度并可用辅助技术操作

## 测试（含安全负面测试）
- E2E：录制/取消/权限拒绝
- 无障碍：语音消息的读屏名称与状态
- 安全负面：名片不泄露未授权资料字段
- 安全负面：超长/畸形音频被拒绝
