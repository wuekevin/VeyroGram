# Story 16.7: 机器人与服务账号

**Epic 16：开放平台基础（本 Story：Phase 5）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 开发者,
I want 创建机器人与服务账号，在被邀请的会话里收发消息，向订阅用户发服务消息,
So that 自动化与通知能力.

## 验收标准（Acceptance Criteria）
**Given** 机器人
**When** 访问未被邀请的会话
**Then** 返回 403，被移出后立即失效

**Given** 服务消息
**When** 用户未订阅或已退订
**Then** 不送达，模板需审核

**Given** 机器人调用
**When** 发信
**Then** 经业务服务而非直连 IM 内核

## 测试（含安全负面测试）
- 安全负面：机器人越权访问会话
- 集成：与 imgw 的调用边界
- E2E：邀请-收发-移出
