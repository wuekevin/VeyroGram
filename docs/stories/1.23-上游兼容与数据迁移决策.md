# Story 1.23: 上游兼容与数据迁移决策

**Epic 1：账号与最小聊天纵切（可信基座）（本 Story：Phase 2）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 产品负责人,
I want 决定是否需要兼容或迁移上游 TangSengDaoDao 的数据与旧客户端，并落实,
So that 避免默默破坏既有部署或假设“绿地”.

## 验收标准（Acceptance Criteria）
**Given** 上游数据表与旧路径
**When** 评估
**Then** 输出书面决策：是否提供 compat 层与数据迁移、兼容窗口与下线日期

**Given** 决定提供迁移
**When** 执行
**Then** 迁移脚本幂等、可回滚并有校验报告

**Given** 决定不提供
**When** 发布
**Then** 在文档明确声明并保留“全新部署”路径

## 测试（含安全负面测试）
- 迁移：样例库迁移演练
- 回滚：迁移失败回退
- 契约：compat 层路径清单
