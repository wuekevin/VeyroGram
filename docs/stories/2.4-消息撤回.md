# Story 2.4: 消息撤回

**Epic 2：完整的消息体验（本 Story：Phase 3）** · 规模 M（S=半天–1天，M=1–3天，L=3–7天；按单个开发 Agent 的上下文可完成估算）

As a 终端用户,
I want 在时限内撤回自己发送的消息，所有设备一致,
So that 发错内容可以补救.

## 验收标准（Acceptance Criteria）
**Given** 自己的消息在时限内（默认 3 分钟，可配置）
**When** 撤回
**Then** 所有设备含离线设备最终显示撤回提示

**Given** 消息已撤回
**When** 通过历史同步、搜索、预览读取
**Then** 服务端均不返回原内容；下载 URL 在 TTL（≤5 分钟）内失效，敏感内容走代理下载则立即失效

**Given** 超过时限
**When** 尝试撤回
**Then** 被拒绝并提示

## 测试（含安全负面测试）
- 安全负面：撤回后的所有读取路径拒绝（T-05）
- 一致性：离线设备重连后状态正确
- E2E：撤回多端
