# DESIGN-SYSTEM — VeyroGram（v0.1 草案）

## 1. 令牌流水线（单一来源，AD-17）
`packages/design-tokens/tokens.json` → `build.py` → `dist/tokens.css`（Web/桌面/官网/开发者平台/管理后台）· `dist/android/colors.xml` + `android-night/colors.xml` · `dist/ios/VGTokens.swift`（引用的 `UIColor(hex:)` 扩展由 iOS 工程提供，尚未写）。
对比度由 `check_contrast.py` 在 `build.py` 写入前**实际计算**：明/暗及渐变共 51 项检查全部通过（正文类 ≥ 4.5:1；焦点环、主色边界、输入框强边框 ≥ 3:1；最低正文类 5.23:1）；任一不通过则构建失败（已做反向验证：把 `text-secondary` 改成浅灰后构建被拒绝、不产出令牌）。`border` 是装饰性分隔，不满足 3:1，需识别边界的控件用 `border-strong`；占位符用 `text-placeholder`，气泡内次要文字用 `on-bubble-*-secondary`。

## 2. 组件清单（Phase 3 前先出高保真原型）
基础：按钮（主/次/文字/危险/图标）、输入框、开关、复选/单选、选择器、分段控件、头像（含群头像拼图）、徽标/未读点、标签 Chip、列表项、分组标题、分割线。
IM：会话列表项、消息气泡（文本/图片/语音/名片/文件/位置/小视频/通话记录/系统消息/撤回提示/未知类型降级）、输入栏、附件面板、表情面板、引用块、已读详情、消息长按菜单。
反馈：Toast、Snackbar、对话框、底部弹层、权限说明弹窗、骨架屏、空状态、错误状态、离线条。
导航：底部 Tab、桌面左栏、顶栏、面包屑（后台）、侧栏（后台）。
后台：数据表格（列配置/筛选/批量/导出审批）、详情抽屉、审批流条、审计时间线、图表卡片、表单区块。
开放平台：密钥展示块（一次性展示 + 复制）、scope 授权列表、版本时间线、审核状态条、API 调试面板。

## 3. 图标规则
24px 网格，live area 20，描边 1.75，圆角端点/连接；状态集：默认/选中（填充强调色或加粗）/禁用/徽标叠加。现有 69 个原创 SVG（`brand/icons/ui/`），含 `icons.json`（中英文无障碍名称）与 `sprite.svg`；评审后补充了相机、附件、警告、信息、已读双勾、离线、chevron、刷新、共享屏幕、挂断、关闭摄像头、静音，并把 `moments` 改为轨道图形以消除与相机的歧义。**尚无选中/禁用/徽标叠加的状态集资产**，只有默认态。**导航/工具栏/Tab/后台菜单禁止 Emoji**，用 `tools/lint_no_emoji_nav.py` 检查。实测：路径或行内像 UI 外壳定义（router/menu/icon/title…）的 Emoji 会被发现（含 `router/index.ts`）；快捷键符号 `⏎` 与聊天文本 Emoji 不会误报；对上游 Manager 源码扫描 0 项。它是**启发式检查，不是证明**。**目前仓库没有 CI 配置**，因此尚无任何“CI 阻断”；已提供 `.github/workflows/design-checks.yml` 草案（未在 CI 上运行过）。新增图标须通过 `tools/build_icons.py` 注册。
状态：v0.1 手工绘制草稿，已在明/暗背景下目检；**尚未经设计师评审**，部分图标（如表情 `sticker`、`wallet`）需精修。

## 5. 审批门禁（编码前）
**材料已就绪（2026-11-19）：** 22 个原型页（含 4 个英文版）、94 张截图基线（手机 390×844 与 360×780、平板 834×1112、桌面 1440×900/1100×700；明/暗；7 个关键页另有 200% 字号版）、组件规格 `COMPONENT-SPECS.md`、令牌与对比度脚本、WCAG 2.1 AA 50 条清单与复核指南。覆盖流程新增：设备批准、设备管理、扫码登录（桌面+手机确认）、小程序授权同意页、小程序市场、客服工作台、已读详情、消息编辑、设置页、平板双栏。
**自动化证据：** `tools/a11y_scan.py` 在**精确视口**中运行 96 次（22 页 + 英文 + 200% 字号 + 320px 回流，明/暗），axe-core + 键盘焦点环 + 目标尺寸 + 文字裁切 + 横向滚动，**当前 0 项发现**，检查了 516 个可聚焦元素；axe 无法判定的 44 项（渐变/叠层上的文字对比）已手算并催生了 `gradient.action` 令牌。扫描过程中发现并修复的真实缺陷：输入框无焦点环、链接点击目标 16px、模态背景未 inert、可滚动区域不可聚焦、200% 字号下输入框溢出/文字重叠、渐变按钮深色文字在紫端仅 3.99:1。
